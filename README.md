# PunchScope 冲孔板检查

PunchScope 在有背光的冲孔板照片上作原片点读、通光面积、孔件量取、水平截线和板边检查。上传背光原片，或从「合成练习」选一张示例，拖出量区，设置截线和亮度阈值并更新。检查卡保留原片和当前设置，可从卡片列表重开。

## 启动

桌面浏览器访问 http://127.0.0.1:19930。Compose 为本项检查卡与照片准备区使用单独的命名卷，关闭时保留数据。

```sh
docker compose up --build -d --wait
docker compose down
```

本机已有 Python 3.11 或 3.12 时，也可将 requirements.txt 安装到独立环境后运行 `./start.sh`。直接启动默认端口 8000，通过 `PORT` 更改，通过 `PUNCHSCOPE_DATA` 指定数据目录，默认目录为 `.punchscope-data/`。

## 日常使用

- 原片支持单帧 PNG、JPEG、TIFF、BMP、WebP。文件最多 18 MiB，归一方向后边长 32–2600 像素且最多 400 万像素。点读坐标使用归一方向后的原片像素，量区的右、下边界不包含该坐标。
- 「框选量区」拖出检查范围。「定位截线」在原片点一个高度。提交更改后，实线、读数、下载才进入新版。点击灰度曲线可在对应的原片行列点读。
- 通光和孔件基于同一亮度阈值和面积下限。孔件为量区内八连通亮区。剪到量区边的孔件允许查看可见面积，完整直径留空。孔件表至多列出面积最大的 500 个，通光面积和识别数仍使用整个量区。内接圆直径是离散像素估计。
- 长孔可在孔件表中点行或「选扁规」，得到一块沿孔长方向、整块都落在本孔透光区里的直矩形；默认取宽×深最大的 Pareto 矩形，也可拖动规宽查看放宽与进深的取舍。读数给出规的位置、宽度与进深（px/mm）。矩形若会压到缺口、挡料，或孔件被量区裁断，则不出通过规。点「采用」后，在截线灰度图上沿规长点一个位置，即从规的两个短向边向两侧扫描，逐像素读到原孔壁为止的间隙（px/mm）；遇到第一处非本孔像素（孔壁/板料）即停，不会跨过板料把另一处亮点计入间隙。对应接口为 `cards/<id>/gauge` 与 `cards/<id>/gauge/clearance`（另有 `/flat-gauge`、`/clearance`、`/gap(s)` 别名，间隙接口兼容 GET 查询与 POST JSON）。
- 以照片上可辨认的标尺输入像素每毫米，节距和板高随标尺换算。现有换算使用全片同一比例。未校正的透视、复杂反光或照明梯度会影响读数。板高来自同一原片列的上下边，只有同时找到两侧时该列才计入。
- 保存截线 CSV、带图层检查图、原片量区裁样或包含前述材料的 ZIP。需要通用的原片取像、调色、裁剪与输出时，点击「原片送去准备」，用图像准备工作台继续操作。检查卡保持原来记录。
- 整板、缺孔与偏位、长孔、眩光练习由程序绘制，都是合成输入。检查卡库上限为 120 张。

应用后端包含 punchscope 测量工作台和本地复用的 image_lab 图像准备服务。有效 Python 行数可以用 `python scripts/count_backend.py --project-root . --source-root punchscope --source-root image_lab` 复算。
